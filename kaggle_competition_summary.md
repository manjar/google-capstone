# AI Agents Intensive Capstone Project - Competition Summary

## Overview
Capstone project for the 5-Day AI Agents Intensive Course with Google (Nov 10-14, 2025).

**Deadline:** December 1, 2025, 11:59 AM PT
**Winners Announced:** Before end of December 2025

## Tracks (Choose ONE)

1. **Concierge Agents** - Personal automation (meal planning, shopping, travel)
2. **Agents for Good** - Education, healthcare, or sustainability
3. **Enterprise Agents** - Business workflows, data analysis, customer support
4. **Freestyle** - Innovative agents that don't fit other categories

## Prizes
- Top 3 teams per track: Kaggle swag + social media feature
- All participants: Badge + certificate of participation

## Submission Requirements

### Required Features (minimum 3)
- **Multi-agent system**: LLM-powered, parallel, sequential, or loop agents
- **Tools**: MCP, custom tools, built-in tools (Google Search, Code Execution), OpenAPI tools
- **Long-running operations**: Pause/resume agents
- **Sessions & Memory**: State management, long-term memory, context engineering
- **Observability**: Logging, tracing, metrics
- **Agent evaluation**
- **A2A Protocol**
- **Agent deployment**

### Submission Components
1. **Track selection** (one only)
2. **Problem/solution pitch**
3. **Published code** (GitHub or Kaggle Notebook)
4. **Written articulation** of agent value
5. **Video** (optional, for bonus points)

## Evaluation Criteria (100 points max)

### Category 1: The Pitch (30 points)
- **Core Concept & Value** (15 pts) - Innovation, relevance, meaningful agent use
- **Writeup** (15 pts) - Problem articulation, solution, architecture, journey

### Category 2: Implementation (70 points)
- **Technical Implementation** (50 pts) - Architecture quality, code quality, meaningful agent use
- **Documentation** (20 pts) - README with problem, solution, architecture, setup instructions

### Bonus Points (up to 20 pts, max total 100)
- **Gemini usage** (5 pts) - Using Gemini to power agent(s)
- **Agent Deployment** (5 pts) - Deployed via Agent Engine or cloud runtime
- **YouTube Video** (10 pts) - Under 3 min covering: problem, why agents, architecture, demo, build process

## Team Rules
- Maximum 4 members per team
- One submission per team
- Each person can only be on one team

## Submission Format
- Title + Subtitle
- Card/Thumbnail image
- Track selection
- Media gallery (optional YouTube video)
- Project description (<1500 words)
- Code attachments (GitHub repo OR Kaggle Notebook)
